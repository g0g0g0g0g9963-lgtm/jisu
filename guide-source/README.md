# 회의실 예약 이용가이드 작업원본

이 폴더에는 이용가이드를 다시 수정하는 데 필요한 파일을 한곳에 모아 두었습니다.

- `update_usage_guide.py`: 가이드 PDF 생성 파일
- `assets/`: 가이드에 사용한 캡처 이미지
- `base/회의실예약_매뉴얼_기준본.pdf`: 반복 편집 시 사용하는 기준 PDF

`update_usage_guide.py`를 실행하면 다음 세 파일이 함께 갱신됩니다.

- `output/pdf/회의실예약_이용가이드.pdf`
- `public/회의실예약_매뉴얼.pdf`
- `dist/회의실예약_매뉴얼.pdf`

다른 PC에서 작업할 때는 OneDrive 동기화가 끝난 후 `회의실 예약2` 폴더 전체를 열어 작업합니다. 임시 폴더나 `.codex` 폴더의 파일은 사용하지 않습니다.
