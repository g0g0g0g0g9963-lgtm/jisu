# Windows 실행 파일 (start-meeting-room.bat)

내 PC(Windows)에서 더블클릭 한 번으로 최신 코드를 내려받고 사이트를 열어보기 위한 실행 파일입니다.

파일 이름과 화면에 나오는 안내 문구는 영어로만 되어 있어요. 한글로 된 이전 버전(`회의실예약_실행.bat`)은
전송/콘솔 코드페이지 문제로 글자가 깨지는 문제가 있어서, 이 문제를 원천적으로 피하려고 영어로 바꿨습니다.
사이트 화면 자체(브라우저에 뜨는 내용)는 그대로 한글입니다 — 이 배치 파일의 콘솔 창 안내문만 영어예요.

## 설치 방법

1. `start-meeting-room.bat` 파일을 아래 폴더에 저장합니다. (이전에 받은 `회의실예약_실행.bat`은 지워도 됩니다.)
   ```
   C:\Users\김지수JisuKim\OneDrive - BDO Korea\바탕 화면\Claude\회의실 예약
   ```
2. 그 파일을 더블클릭해서 실행합니다.
3. 처음 실행할 때는 다음을 자동으로 합니다.
   - Git / Node.js / pnpm 설치 여부 확인 (없으면 설치 안내 메시지를 보여주고 종료)
   - 같은 폴더 안에 `app` 하위 폴더를 만들고 GitHub 저장소 코드를 내려받음
     (처음 다운로드할 때 브라우저로 GitHub 로그인 창이 뜰 수 있어요 — 로그인해서 저장소 접근을 허용해 주세요)
   - 필요한 패키지 설치 (`pnpm install`)
   - 사이트를 실행하고 기본 브라우저로 자동으로 열어줌 (`http://localhost:3000`)
4. 다음부터 실행할 때는 매번 GitHub의 최신 코드로 업데이트한 뒤 사이트를 다시 실행합니다.

## 참고

- 실제 코드/설치 파일(`node_modules` 등)은 `회의실 예약\app` 폴더 안에 생성됩니다. 파일 수가 많아서 OneDrive
  동기화가 느려질 수 있으면, OneDrive 설정에서 `app` 폴더만 동기화 제외하거나 "이 기기에서 항상 보관"을
  꺼두는 것을 추천합니다. (코드는 GitHub에 있으니 다시 받으면 되기 때문에 동기화 제외해도 안전합니다.)
- 사이트를 실행하는 서버는 최소화된 콘솔 창(`BDO Meeting Room Server`)으로 백그라운드에서 계속 돌아갑니다.
  완전히 끄고 싶으면 그 창을 닫으면 됩니다.
- 이 배치 파일 자체는 `app` 폴더 밖에 있어서 자동으로 업데이트되지 않습니다. 실행 방식(배치 파일 로직)을
  바꿔야 하면 새 버전 파일을 다시 받아서 같은 위치에 덮어써야 합니다.
- 지금 코드는 아직 `main`이 아니라 `claude/setup-continuation-217xow` 브랜치에 있습니다. 이 배치 파일은
  그 브랜치를 기준으로 최신화합니다. 나중에 `main`으로 병합되면 파일 위쪽의 `BRANCH` 값을 `main`으로
  바꿔주면 됩니다.
